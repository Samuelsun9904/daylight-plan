# 日序

个人清单与日历应用，可像「周期记」一样添加到 iPhone / iPad 主屏幕。首次联网加载完成后，可以离线启动、记录和修改计划，电脑无需运行。

## 手机上使用

正式地址：https://samuelsun9904.github.io/daylight-plan/

1. 用 Safari 打开。
2. 分享 → 添加到主屏幕。
3. 如果有“作为网页 App 打开”，保持开启。
4. 之后点击桌面“日序”图标打开。

## 功能

- 今天、明天、本周、下周、本月、未安排、逾期、已完成、回收站。
- 月历和按天排列的七列周视图，手机横向滚动。
- 新增、编辑、改期、复制、删除和恢复。
- 历史补建、补记实际完成日期、撤销完成。
- 分类、重要程度、可选时间、备注、搜索和完成项显示偏好。
- 完整 JSON 备份导出及验证后合并导入。
- 主屏幕图标、独立窗口、离线页面缓存。
- localStorage 主存储与 IndexedDB 设备内备用快照。

## 保存与同步

未登录的计划只保存在当前设备；登录并合并后保存到自己账号的云端空间，不上传到 GitHub。公开仓库只发布程序代码、图标和样式，不包含用户数据库、备份或计划。

**苹果手机与华为平板可使用同一邮箱账号同步。** 在设置中使用周期记已有邮箱、密码登录。未登录计划先保留在设备，确认“合并本机计划”后才上传到账号。两台设备都会在前台定期同步，也支持立即同步、离线修改与恢复联网后补传。

云端需先在周期记同一个 Supabase 项目执行 `migrations/001_private_sync.sql`。脚本只创建日序表和按账号隔离的权限，不修改周期记数据；前端仅含可公开的 Publishable key。

退出账号会切回未登录本机记录，原账号缓存和待同步队列仍保留，下次登录继续提交。不同字段修改按补丁合并；同字段冲突保留原版本为副本；重试操作不会重复执行。云端读取分页，避免 1000 条上限截断。

设备内备用快照仍属于同一设备，并不是云备份。清除网站数据或移除应用可能删除设备记录，请定期导出。

系统通知、重复计划和原生安装包尚未接入。时间字段只用于显示和排序。原朝暮数据没有自动迁移；导入目前接受日序 JSON 格式。

## 开发与本机服务

静态应用在 `public/`，可直接托管到 HTTPS 子目录。`runtime-config.js` 默认使用设备存储；没有任何本机 API 依赖。

可选的 Python 服务仅用于本机开发：

```bash
python3 server.py
```

打开 http://127.0.0.1:8765 。此服务会提供服务模式配置，数据存入 `data/rixu.sqlite3`。默认只监听本机；可信局域网测试可以加 `--host 0.0.0.0`。没有账号认证，不应将此开发服务直接暴露到公网。

## 验证

```bash
npm run check
npm test
python3 -m unittest discover -s tests -v
```

`tests/pwa_qa.py [URL]` 通过 Chrome CDP 测试主屏幕配置、静态子目录部署、断网重开、离线修改持久化、备用快照恢复及其他应用缓存隔离。需要本机 Chrome 的 9227 调试端口。

浏览器自动检查不等于真实 iPhone / iPad 验证；实际安装请在目标设备按上方步骤完成。

数据库权限、字段合并、冲突副本与幂等检查：安装测试依赖 `@electric-sql/pglite` 后运行 `node tests/sql-sync-qa.cjs`。云端初始化前的本地自动检查不代表已经完成真实账号与真机双端验证。
