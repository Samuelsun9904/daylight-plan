# 日序

个人清单与日历应用，可像「周期记」一样添加到 iPhone / iPad 主屏幕。首次联网加载完成后，可以离线启动、记录和修改计划，电脑无需运行。

## 手机上使用

正式地址：https://samuelsun9904.github.io/daylight-plan/

1. 用 Safari 打开。
2. 分享 → 添加到主屏幕。
3. 如果有“作为网页 App 打开”，保持开启。
4. 之后点击桌面“日序”图标打开。

## 功能

- 今天、明天、本周、下周、本月、未安排、逾期、已完成、回收站。
- 月历和按天排列的七列周视图，手机横向滚动。
- 新增、编辑、改期、复制、删除和恢复。
- 历史补建、补记实际完成日期、撤销完成。
- 分类、重要程度、可选时间、备注、搜索和完成项显示偏好。
- 完整 JSON 备份导出及验证后合并导入。
- 主屏幕图标、独立窗口、离线页面缓存。
- localStorage 主存储与 IndexedDB 设备内备用快照。

## 保存与同步

线上版计划只保存在当前设备，不上传到 GitHub。公开仓库只发布程序代码、图标和样式，不包含用户数据库、备份或计划。

**手机和平板当前各自保存数据，尚未接入跨设备云同步。** 可以先用设置中的导出、导入备份转移。设备内备用快照仍属于同一设备，并不是云备份。清除网站数据或移除应用可能删除设备记录，请定期导出。

云同步、系统通知、重复计划和原生安装包尚未接入。时间字段只用于显示和排序。原朝暮数据没有自动迁移；导入目前接受日序 JSON 格式。

## 开发与本机服务

静态应用在 `public/`，可直接托管到 HTTPS 子目录。`runtime-config.js` 默认使用设备存储；没有任何本机 API 依赖。

可选的 Python 服务仅用于本机开发：

```bash
python3 server.py
```

打开 http://127.0.0.1:8765 。此服务会提供服务模式配置，数据存入 `data/rixu.sqlite3`。默认只监听本机；可信局域网测试可以加 `--host 0.0.0.0`。没有账号认证，不应将此开发服务直接暴露到公网。

## 验证

```bash
npm run check
python3 -m unittest discover -s tests -v
```

`tests/pwa_qa.py [URL]` 通过 Chrome CDP 测试主屏幕配置、静态子目录部署、断网重开、离线修改持久化、备用快照恢复及其他应用缓存隔离。需要本机 Chrome 的 9227 调试端口。

浏览器自动检查不等于真实 iPhone / iPad 验证；实际安装请在目标设备按上方步骤完成。
